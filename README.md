# Life Dashboard

A responsive personal productivity dashboard built with HTML, CSS, and Vanilla JavaScript.

## Features

- Real-time clock and date
- Time-based greeting
- Custom name in greeting
- Pomodoro focus timer
- Custom Pomodoro duration
- To-Do list with add, edit, complete, and delete
- Clear All To-Do
- Local Storage persistence
- Quick Links with customizable websites
- Light and Dark Mode
- Dino completion reward animation
- Responsive design for desktop, tablet, and mobile
- Accessible and translation-friendly interface

## RevoU Coding Camp Challenges

This project implements the following three challenges:

1. Light / Dark Mode
2. Custom Name in Greeting
3. Change Pomodoro Time

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage API
- Web Audio API

No framework or backend is required.

How to Run

Open index.html in a modern web browser.

Recommended browsers:

Google Chrome
Mozilla Firefox
Microsoft Edge
Safari
Data Storage

The application uses the browser Local Storage API to persist:

User name
Theme preference
Pomodoro duration
To-Do tasks
Quick Links
Dino Completion Reward

Completing one or more tasks triggers a short visual reward using the existing Dino assets.

The reward is intentionally lightweight and does not interfere with normal task management.
